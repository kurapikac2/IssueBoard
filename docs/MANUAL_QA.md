# Ручная browser проверка

Этот checklist подготовлен, но не выполнен в текущей среде:
Chrome отсутствует; browser host недоступен; native Zen не предоставляет input geometry.

1. Запустить локальное приложение с отдельной ISSUEBOARD_DB для тестовых данных.
2. Проверить / на desktop 1440x900 и mobile 390x844, затем 320x640.
   Не должно быть горизонтального скролла страницы или недоступных кнопок.
3. Создать аккаунт; повторить регистрацию с тем же именем — понятная ошибка.
4. Войти с неверным паролем, затем с верным. Проверить пустое рабочее пространство.
5. Создать два проекта; переключаться между ними и перезагрузить страницу.
6. Создать bug с high/open; task с medium/in_progress; task с low/done.
7. Найти по части названия на кириллице, совместить статус и приоритет.
   Проверить оба направления сортировки после редактирования старого issue.
8. Открыть issue; изменить название без смены статуса — нет новой записи истории.
9. Сменить статус — видны автор, старое/новое значение и время.
   Показатели меняются независимо от фильтров списка.
10. Нажать удаление и отменить — issue остаётся. Затем подтвердить на тестовом issue.
11. Проверить пустой результат поиска и сброс фильтров.
12. Пройти интерфейс клавиатурой: Tab, Shift+Tab, Enter, Escape в dialogs.
13. Проверить ошибки сети при временно остановленном локальном сервере.
14. Открыть второй browser profile с другим аккаунтом: чужой project URL не даёт доступ.
15. Logout; перезагрузка не возвращает доступ.

Перед публикацией screenshots используйте только специально созданные
тестовые данные без личной информации. Не включайте адресную строку,
другие вкладки, cookie и DevTools со значениями tokens.
